# Loami feedback

Help improve [Loami](https://loami.dev). Report bugs, suggest improvements, and follow progress in [Issues](https://github.com/Darthwares/loami-feedback/issues).

Search existing issues first. Include what you expected, what happened, and steps to reproduce. For feature requests, explain the problem you want to solve.

Everything here is public. Never post private documents, customer information, access tokens, or private workspace links. For security vulnerabilities, follow the security contact at https://loami.dev/security/ instead of opening a public issue.

An issue is a tracking record, not a delivery commitment. We will label and update requests as they are reviewed.
